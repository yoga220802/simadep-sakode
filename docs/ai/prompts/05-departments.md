# Prompt 05 — Department Management

Implement department vertical slices:

- browse departments;
- create/update/archive department;
- manage department members;
- department role policies;
- department-aware navigation/filter.

Requirements:

- head/admin/member/viewer roles;
- prevent orphaning last head without transfer/archive flow;
- scoped queries;
- audit and outbox events;
- unit denied-path tests;
- MySQL integration tests when available;
- no project implementation beyond required relation scaffolding.
